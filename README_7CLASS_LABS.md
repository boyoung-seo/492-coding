# 492 Coding — Seven-Class Causal Analytics Labs

These labs align to the seven class decks:

1. RCTs and broken experiments
2. Pseudo/natural experiments + SQL
3. Controls: confounders, colliders, mediators
4. Instrumental variables
5. Panel fixed effects
6. Regression discontinuity
7. Matching: stratification + synthetic matching

Each lab lives under `labs_7class/` and contains a student notebook plus a `data_dictionary.csv`. All public datasets live in `data/`.

Student notebooks load files directly from:
`https://raw.githubusercontent.com/boyoung-seo/492-coding/main/data/...`
